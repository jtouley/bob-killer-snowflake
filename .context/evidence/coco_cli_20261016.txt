=== cortex exec --help
Usage: cortex exec [options] <message>
       cortex exec [options] --file <path>
       cortex exec [options]              (reads prompt from stdin)

Execute cortex non-interactively. Designed for CI/CD pipelines.
Plan mode is always disabled. Interactive prompts are auto-rejected.

Options:
      --format        Output format: text (default) or json
      --allowed       Tools that may run (all others blocked). May be repeated or comma-separated.
      --blocked       Tools that are blocked (all others allowed). May be repeated or comma-separated.
      --file          Read prompt from a file (use - for stdin)
  -m, --model         Model override
      --mode          Agent mode: standard, code, or rem
  -c, --connection    Snowflake connection name
  -w, --workdir       Working directory
      --max-turns     Maximum agentic turns (safety ceiling)
      --effort        Thinking effort: minimal, low, medium, high, xhigh, max
      --no-history    Do not save this session to history
      --private       Alias for --no-history
      --no-mcp        Disable MCP servers
      --cloud [<workspace-fqn>]
                      Enable the server-side sandbox; optionally mount the named stage at /workspace.
      --no-workspace  Use an ephemeral /workspace instead of mounting a stage.
      --skills <name=@stage/path>
                      Attach a server-loaded STAGE skill. May be repeated; requires --cloud.
      --mcp <fqn>     Attach an object from SHOW EXTERNAL MCP SERVERS. May be repeated; requires --cloud.
      --eai <name>    Attach an External Access Integration. May be repeated; requires --cloud.
      --with-restricted-session-scope <scope>
                      Bind a well-known or fully-qualified restricted session scope in the sandbox.
      --github <fqn>  Grant the sandbox authenticated git/gh egress via a Snowflake SECRET
                      (e.g. --github USER$YOU.PUBLIC.GITHUB_PAT). Implies --cloud.
      --pre-run-hook <bash>
                      Run inline bash before each server agent run, including continuations.
                      Must be idempotent; requires --cloud.
      --post-run-hook <bash>
                      Run inline bash after each server run response, including continuations.
                      Must be idempotent; requires --cloud.
      --pre-run-timeout <seconds>
                      Pre-run timeout: 0 uses 60s default; maximum 300.
      --post-run-timeout <seconds>
                      Post-run timeout: 0 uses 30s default; maximum 300.
      --bypass        Allow all tool calls without prompting (use with care in trusted environments)
  -o, --output-last-message  Write final response to a file
  -h, --help          Show this help

Examples:
  cortex exec "fix all lint errors"
  cortex exec "explain this codebase" --format json
  cortex exec "update tests" --allowed "Read,Edit,Bash(git *)"
  cortex exec "analyze" -c prod --max-turns 30
  cortex exec --file .cortex/prompts/review-pr.md --allowed "Bash(gh *)"
  cat prompt.md | cortex exec --allowed "Bash(gh *)"
  git diff HEAD~1 | cortex exec "review these changes"
  cortex exec --no-history "one-off query"
  cortex exec --private "one-off query"
  cortex exec "summarize changes" -o /tmp/summary.txt
  cortex exec --cloud "analyze repo" --allowed "Read"
  cortex exec --cloud --github 'USER$YOU.PUBLIC.GITHUB_PAT' "clone and review the repo"
  cortex exec --cloud --pre-run-hook "cd /workspace && git pull --ff-only" "review recent changes"
  cortex exec --bypass "scaffold this project"

cortex mcp

Manage MCP servers

Commands:
  cortex mcp add <name> <commandOrUrl>      Add an MCP server
  [args..]

  cortex mcp list                           List all configured MCP servers
  cortex mcp reconnect [name]               Reconnect MCP server(s). With no
                                            name, retries all
                                            failed/disconnected servers.
  cortex mcp start                          Start MCP servers
